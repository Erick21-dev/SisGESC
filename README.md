# SisGESC
Projeto SisGESC 
O SisGESC (Sistema de Gestão Escolar) é um projeto criado para simular o funcionamento de um sistema acadêmico utilizando banco de dados MySQL.Durante o desenvolvimento foram aplicados conceitos importantes de Banco de Dados, como modelagem relacional, controle de alunos, cursos, matrículas, pagamentos e funcionários.Além da parte transacional (OLTP), o projeto também conta com um ambiente analítico (OLAP), utilizando Star Schema e processos de ETL para análise de dados e geração de informações.O projeto também inclui testes de integridade, transações SQL e otimização de consultas para melhorar o desempenho do banco de dados.

# Estrutura
SQL :  Contém os scripts divididos por fases do projeto.
run_all.sql: Script unificado para rodar todo o projeto com um único comando.
